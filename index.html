Automatic setup

One file, launch.bat. It installs and starts Bushscript for you. For Windows.

  1. Download launch.bat. Use the Download launcher button, or run this in Command Prompt or PowerShell:
curl -L -o launch.bat https://raw.githubusercontent.com/OpenBushate/bushscript/main/launch.bat
  1. Run it. Double-click launch.bat, or run launch.bat in a terminal from the same folder. Windows may ask you to confirm before it runs a downloaded file.
  2. Use Bushscript as your browser. The browser opens on its own. When you close the browser, the program ends.

If your browser shows the file as text instead of saving it, right-click the button and choose Save link as. Want to read it first? Open launch.bat on GitHub.

Manual installation

One file, Bushscript.java. Edit it, keep it anywhere, and run it your way. You need Java and basic Java knowledge. JDK 11 or newer runs a .java file directly.

  1. Download Bushscript.java. Use the button, or run:
curl -LO https://raw.githubusercontent.com/OpenBushate/bushscript/main/script/Bushscript.java
Download Bushscript.java Everything (.zip)
  1. Change it if you like. It is a plain Java source file under the MIT license.
  2. Run it with Java. From the folder that holds the file:
java Bushscript.java
  1. Use Bushscript as your browser. The browser opens, and closing it ends the program.

Make a Windows shortcut

A batch file starts your manual copy with a double-click. In Notepad, paste the line below and replace [USERNAME_HERE] with your Windows username or student email string. If the Java file sits in a package folder, keep that folder in the path.

java C:\Users\[USERNAME_HERE]\Documents\NetBeansProjects\Bushscript\src\bushscript\Bushscript.java

Save it as Bushscript.bat with Save as type set to All Files, then double-click it.

NetBeans setup

No longer recommended

After wide use, the maintainers recommend the setups above. If you still want it, you need NetBeans IDE and Java.

  1. Create the project. Make a new NetBeans project (Ant Application) named Bushscript.
  2. Add the file. Copy Bushscript.java into the project.
  3. Run the project. The browser opens automatically.
